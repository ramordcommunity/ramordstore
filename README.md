## Features

**Ramord Store** is the official desktop application manager and support hub for Linux workstations. It provides an intuitive, modular interface to discover, install, update, and launch Ramord open-source applications, while offering direct support access.

### Highlights

- **Application Management:** Install, update, and launch Ramord applications (Ramord Link, Ramord Cast, Ramord CAD).
- **Direct Email Support:** Every application features a direct support button to open your pre-addressed mail client or copy the official support address.
- **Status Detection:** Automatically detects existing local installations and versions.
- **Obsidian Luxury Design:** Styled with the signature Obsidian Dark Turquoise user interface.
- **Full 6-Language Localization:** English, Turkish, German, Spanish, French, and Italian UI localization.

## Installation

### Automated Setup

Run the installation script to set up application launcher, commands, and universal icon themes:

```bash
git clone https://github.com/ramordcommunity/ramordstore.git
cd ramordstore
bash install.sh
```

### Running the Application

You can launch Ramord Store in either way:
- **Terminal:** Type `ramord-store` or run `python3 main.py` inside the project folder.
- **Desktop Launcher:** Click **Ramord Store** from your desktop or application menu.

## Türkçe Açıklama

**Ramord Store**, Ramord açık kaynak masaüstü uygulamalarını Linux bilgisayarınıza kolayca kurmanızı, güncellemenizi, başlatmanızı ve resmi destek almanızı sağlayan merkezi bir uygulama mağazasıdır.

### Temel Özellikler

1. **Uygulama Yönetimi:**
   - Ramord Link, Ramord Cast ve Ramord CAD uygulamalarını doğrudan kurma, güncelleme ve tek tıkla çalıştırma.
   - Bilgisayarınızdaki kurulu uygulamaların durumunu otomatik olarak algılama.

2. **Doğrudan E-Posta Desteği:**
   - Her uygulamanın yanında ve ana sayfada doğrudan geliştirici ekibine e-posta gönderme butonu.
   - Hata bildirimi ve teknik destek taleplerinde resmi adresi (`ramordhelp@gmail.com`) otomatik olarak açma ve kopyalama.

3. **6 Dilde Tam Destek:**
   - Türkçe, İngilizce, Almanca, İspanyolca, Fransızca ve İtalyanca dil desteği.

4. **Sistem Entegrasyonu:**
   - Tüm Linux masaüstü temalarıyla uyumlu simge yapısı ve masaüstü kısayolu.
